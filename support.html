Before you ask for help

  • Write a short description of what happened and when.
  • Include the service name and transaction reference if one exists.
  • Never share your password, OTP, transaction PIN, recovery code or full bank/card details.
  • Do not send the same request repeatedly while an earlier request is being reviewed.
